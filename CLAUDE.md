# Project Guidelines

## Code Quality & Linting Rules

Whenever editing or creating JavaScript, TypeScript, or Vue files (`.js`, `.jsx`, `.ts`, `.tsx`, `.vue`, `.mjs`, `.cjs`):
- Always run `npx -y oxlint@latest` (or `npx -y oxlint@latest --fix`) immediately after finishing edits.
- If any lint errors or warnings are found, immediately fix them before completing the task.
- Ensure the project remains clean of lint errors.
